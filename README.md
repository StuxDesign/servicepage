# Service Page

A clean and simple placeholder page for a Stux.Design service that hasn't been set up yet.

## Overview

This repository contains a lightweight HTML page shown in place of a Stux.Design service that hasn't been configured yet. It points visitors back to Stux.Design and gives them a way to get in touch.

Like its siblings it's a single static page, but drawn as a designer's artboard: a faint layout
grid, rulers along the edges, a selection box around the headline's highlighted words (tagged
"Blank artboard") and crop marks on the card, all in Stux.Design magenta (`#e71081`).

## Features

- 📄 Simple, clean HTML structure
- ⚡ Lightweight and fast-loading
- 🎨 Ready to customize
- 📱 Responsive design
- 🚀 Deployed at [servicepage.stux.design](https://servicepage.stux.design)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/StuxDesign/servicepage.git
   ```

2. Run `./dev-server.sh` (or `dev-server.bat` on Windows) and open `http://127.0.0.1:8000`.
   DEV_MODE is on by default, so the dev banner shows; pass `--no-dev-mode` to see the page as
   production does

## Customization

Edit the HTML files to:
- Update the message
- Add your branding and logo
- Customize colors and styling
- Include additional links

## Deployment

This project uses GitHub Pages and can be automatically deployed to your desired domain.

The live version is deployed at [servicepage.stux.design](https://servicepage.stux.design).
